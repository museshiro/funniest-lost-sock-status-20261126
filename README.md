## The line

```
Update: I'm lining a bowling shoe now. Four hundred strangers' feet a week. The dryer was a spa compared to this.
```

113 characters. One status update, in the voice of a lost sock that ended up
lining a rental bowling shoe — twisting the obvious dryer material by making
the dryer look like a spa in comparison.

## How to run

Requires Node 22.18+ (runs its TypeScript as-is):

```sh
node main.ts
```

It writes the line to `/output/entry.txt` and nothing else — no relative
file writes, so it exits 0 even with a read-only working directory.
